# Repository Memory

## Stable Context
- **資料來源**：長期記憶的唯一權威來源是 GitHub Issue 與其評論。所有自動化與手動整理的結果皆應以這些原始資料為依據。  
- **手動筆記**：`shared/manual.md` 內的手動筆記屬於 **長期穩定規則**，不會被自動化流程覆寫。  
- **compact‑memory 工作流程**：系統會讀取 `shared/manual.md` 以取得穩定規則與限制，然後根據每日快照蒸餾出可重用的上下文。  
- **Issue 整理窗口**：每日快照只會在「可用 issue」存在時產生跨 Issue 主題、決策與開放環節。若無可用 issue，系統會保留既有記憶，不會產生新內容。  

## Recent Themes
> 目前的每日快照（2026‑10‑30 至 2026‑11‑06）皆未偵測到可用 Issue，故 **沒有可辨識的跨 Issue 主題**。  
- **暫無重複出現的主題**：所有天數的快照均顯示「本次整理視窗沒有可用 issue」，表示近期工作項目可能處於靜止或已全部關閉。  

## Constraints
1. **原始資料限制**  
   - 必須以 GitHub Issue / comment 為唯一的事實來源。  
   - 手動筆記僅作為輔助說明，不能取代或覆寫 Issue 中的具體資訊。  

2. **自動化行為限制**  
   - 若每日快照未找到可用 Issue，系統只能保留既有記憶，不能自行創建或推測新規則。  
   - `shared/manual.md` 只允許 **讀取**，不允許 **寫入** 或自動更新。  

3. **資訊不確定性**  
   - 目前缺乏任何新 Issue、決策或跨 Issue 主題的實際資料，所有未出現的資訊皆視為 **未知**，不可假設為穩定事實。  

## Open Loops
