# Repository Memory  

## Stable Context  
- **資料來源**：所有長期記憶皆以 GitHub **issue / comment** 為唯一原始資料來源，日常快照只負責彙整與抽象化。  
- **compact‑memory 工作流程**：  
  - `shared/manual.md` 用於手動維護的長期規則、決策與限制，系統會 **讀取** 但 **不會覆寫**。  
  - 每日快照 (`daily/*.json`) 只保留 **摘要**，不會直接寫入長期記憶。  
- **摘要原則**：  
  - 只蒸餾出 **可重用的上下文**（規則、慣例、限制），避免逐段複製原文。  
  - 若當天無可用 issue，保留既有記憶不做變更。  
- **技術限制**：  
  - 只檢視最近 **30 天**、最多 **100 個** issue。  
  - 摘要方式為 **deterministic**，確保同樣輸入產生相同輸出。
