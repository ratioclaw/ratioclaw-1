# Repository Memory

## Stable Context
- **記憶維護原則**  
  - 只從 GitHub Issue / Comment 中抽取資訊，原始文字不直接搬入本檔。  
  - `shared/manual.md` 為人工維護的長期記憶區，保存 **穩定規則、長期決策、常見限制、repo 習慣**，本檔不會覆寫它。  
  - `compact‑memory` 工作流程會讀取本手動筆記，但不會自動修改；所有自動化的摘要必須遵守此規則。  

- **repo 習慣**  
  - 每日快照 (daily snapshots) 只在有可用 Issue 時產出跨 Issue 主題、決策與開放環節。  
  - 若快照期間無 Issue，則保留既有記憶，不新增內容。  

- **資訊層級**  
  - **長期記憶**：手動筆記中的規則與決策。  
  - **近期主題**：最近 30 天內多次出現的跨 Issue 主題。  
  - **開放環節**：尚未解決或缺乏足夠資訊的事項。  

## Recent Themes
> 目前的每日快照（2026‑09‑16 至 2026‑09‑22）皆顯示「本次整理視窗沒有可用 issue」，因此在最近 30 天內未偵測到任何可重複出現的跨 Issue 主題或趨勢。  

## Constraints
1. **不複製原始 Issue 文字**：所有摘要必須以概念性、精煉的方式呈現，避免直接搬貼。  
2. **手動筆記優先**：`shared/manual.md` 中的內容視為最高可信度的長期規則與限制。  
3. **資訊來源透明**：若資訊來源不明或相互矛盾，必須在本檔中標註「不確定」或「衝突」狀態。  
4. **更新節奏**：只有在 Issue 有變動（新增、關閉、評論）時，才會在每日快照中產生可用資訊；否則保持現有記憶不變。
