# Repository Memory

## Stable Context
- **資訊來源**：本倉庫的長期記憶以 **GitHub Issue / Comment** 為唯一原始資料來源，所有日常摘要皆由活躍的 issue agents 從這裡抽取。  
- **手動筆記 (`shared/manual.md`)**：保存 **穩定規則、長期決策、常見限制、repo 習慣**，供所有 agents 參考。此檔案 **不會被自動覆寫**，亦不應直接複製完整的 issue 內容。  
- **compact‑memory 工作流程**：會在每次執行時讀取 `shared/manual.md`，並以此為基礎蒸餾每日快照，產出可重用的長期記憶。  
- **記憶整理原則**：  
  1. 只保留 **可重用的規則或事實**，不逐段搬錄原始日誌。  
  2. 若資訊僅在單一天出現且未形成穩定事實，則歸入 **近期主題** 或 **Open Loops**，不寫成永久規則。  
  3. 若資訊不足或相互矛盾，必須在此處標示 **不確定性**。  

## Recent Themes

- **當前狀態**：倉庫處於 **靜止期**，沒有新議題、標籤或決策可供蒸餾。
