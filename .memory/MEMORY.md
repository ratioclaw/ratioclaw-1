# Repository Memory

## Stable Context
- **記憶守則**：本倉庫的長期記憶由 **龍蝦團隊** 依據 GitHub Issue / Comment 原始資料彙整，**不會直接複製完整的 Issue 文字**，而是抽取關鍵規則、決策與限制，形成可重用的上下文。  
- **手動筆記**：`shared/manual.md` 為人類手動維護的長期記憶區，主要保存 **穩定規則、長期決策、常見限制** 以及 **repo 內部慣例**。此檔案不會被自動流程覆寫。  
- **資料來源**：所有自動化的日誌（`daily/*.json`）僅作為 **快照**，用來偵測跨 Issue 的主題與新決策，最終結果仍須回寫至手動筆記或其他永久儲存位置。  
- **目前狀態**：截至 2026‑09‑10，過去 30 天內 **沒有可用的 Issue** 被檢測到，故沒有新增的穩定規則或決策可加入本記憶。

## Recent Themes
- **無跨 Issue 主題**：連續七天的日誌皆顯示「目前沒有可辨識的跨 issue 主題」。
- **無新決策**：同樣沒有任何跨 Issue 的新決策產生。  
> 近期的觀測顯示，倉庫在此段時間內處於靜止或缺乏活躍的 Issue 流程。

## Constraints
1. **不複製原始 Issue 文字**：記憶內容必須是抽象化、概念化的描述，避免直接貼上 Issue 內容。  
2. **依賴 Issue / Comment 為唯一事實來源**：任何新增的規則或決策必須能在 GitHub 上追溯到相應的 Issue 或 Comment。  
3. **手動筆記不可被自動流程覆寫**：`shared/manual.md` 只接受人工編輯，系統僅讀取不寫入。  
4. **每日快照僅作為暫存**：`daily/*.json` 只用於偵測變化，最終記憶必須匯總至長期記憶區。  
5. **資訊不確定時需標示**：若某件事僅在單一天出現且無法驗證為穩定事實，必須放入「Open Loops」或以「不確定」標註。
