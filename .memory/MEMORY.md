# Repository Memory

## Stable Context
- 目前 **沒有** 從 issue 中觀測到可確認的長期規則或決策。  
- 共享手動筆記 (`shared/manual.md`) 提示應在此區塊記錄 **穩定規則、長期決策、常見限制、repo 習慣**，但目前檔案內僅有說明文字，未列出具體內容。  
- **不確定性**：缺乏實際 issue 資料，使得此區塊暫時保持空白，待日後有可驗證的規則或決策時再補充。

## Recent Themes
- 最近 30 天的每日快照（2026‑09‑30 至 2026‑10‑07）皆顯示 **無可用 issue**，因此沒有跨 issue 的主題或重複出現的討論。  
- **不確定性**：若未來出現新 issue，可能會形成新的主題，需持續觀測。

## Constraints
- 目前未偵測到任何 **限制條件**（例如：技術限制、流程規範、資源上限等）。  
- 共享手動筆記中提到「常見限制」應被記錄於此，但尚未提供具體條目。  
- **不確定性**：缺乏實際限制資訊，無法列出具體約束。

## Open Loops
- **等待下一輪 issue 更新**：所有每日快照皆顯示「等待下一輪 issue 更新後再整理」，表示目前的工作流正處於待命狀態。  
- 需要持續監控 issue 列表，當新 issue 出現時，應立即：
  1. 評估是否形成新的 **Stable Context**（穩定規則）或 **Recent Themes**（近期主題）。
  2. 判斷是否產生 **Constraints**（限制）或 **Open Loops**（未完成事項）。
- 若在未來的快照中出現臨時性或一次性的資訊，應將其歸入此 **Open Loops** 區塊，待確認其是否會演變為穩定規則再搬移。
