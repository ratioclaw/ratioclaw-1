# Repository Memory

## Stable Context
- 目前 **沒有** 從 issue 或手動筆記中萃取到可確認的長期規則、決策或共通限制。

- 因此，除非未來的 issue 中明確出現，**此處暫時保持空白**，並以「資訊不足」標註。

## Constraints
- **缺乏可用 issue**：目前的工作流程依賴 GitHub issue 作為原始資料來源，若 issue 為空，系統將無法自動產生新記憶。
