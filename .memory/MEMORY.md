# Repository Memory

## Stable Context
- **記憶管理原則**  
  - 只保留 **穩定規則、長期決策、常見限制** 以及 **repo 共同習慣**，不直接複製 Issue 原文。  
  - 所有原始資訊皆來源於 GitHub Issue / Comment，`shared/manual.md` 只作為 **手動維護的長期記憶**，不會被自動覆寫。  
  - `compact-memory` 工作流程會讀取此手動筆記，以提供上下文給各 agent。

- **目前的 Issue 狀態**  
  - 從 2026‑11‑10 至 2026‑11‑17 的每日快照皆顯示 **無可用 Issue**，因此沒有新增的跨 Issue 主題、決策或標籤。  
  - 這表示在過去兩週內，repo 內部沒有活躍的待辦或討論需要被記錄。

- **龍蝦團隊的角色**  
  - 龍蝦們負責 **蒐集、蒸餾、保存** 主人的長期記憶，確保重要的生活／工作脈絡不會遺失。  
  - 當有新 Issue 出現時，會即時更新本文件的相應章節。

## Recent Themes
- **無可辨識的跨 Issue 主題**  
  - 近期的每日快照皆未偵測到重複出現的議題或主題。  
  - 因此本節暫時保持空白，待未來有持續出現的討論時再補充。

## Constraints
1. **資料來源限制**  
   - 只能引用 **GitHub Issue / Comment** 作為事實依據；手動筆記僅作為摘要與指引。  
2. **避免冗餘**  
   - 不得直接複製完整 Issue 內容，必須以 **精煉、可重用** 的形式呈現。  
3. **更新頻率**  
   - 每日快
