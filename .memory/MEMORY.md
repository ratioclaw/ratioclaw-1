# Repository Memory

## Stable Context
目前 **沒有** 從 issue 中萃取到可視為長期穩定的規則、決策或慣例。  
共享手動筆記 (`shared/manual.md`) 只提供了 **如何** 撰寫長期記憶的指引，並未列出實際的規則或限制。因此在此階段，穩定上下文仍為空白。

## Recent Themes
在最近 7 天（2026‑09‑05 至 2026‑09‑11）的 daily snapshots 中，所有天的報告皆顯示：

- 沒有可用的 issue
- 無跨 issue 主題可辨識
- 無新決策產生

因此近期沒有重複出現的主題可供蒸餾。

## Constraints
- **資訊缺乏**：目前的 issue 資料庫在觀測窗口內皆為空，無法判斷任何限制條件。  
- **手動筆記限制**：`shared/manual.md` 僅說明「穩定規則、長期決策、常見限制」應由人類手動維護，未提供具體內容。  

若未來出現具體限制（例如 CI/CD 流程、代碼風格、部署窗口等），請於手動筆記中補充，以便本記憶庫能自動化蒐集。

## Open Loops
- **等待新 Issue**：所有 daily snapshot 均指出「等待下一輪 issue 更新後再整理」。目前沒有未完成的任務或待決議的議題。  
- **資訊不足**：若未來出現新的 issue、決策或跨 issue 主題，需重新評估並更新本文件的 Stable Context、Recent Themes 與 Constraints。  

> **註**：若您在其他來源（如 GitHub issue、pull request、討論串）中已經定義了穩定規則或限制，請將其手動加入 `shared/manual.md`，以便本記憶庫在未來的整理中能正確反映。
