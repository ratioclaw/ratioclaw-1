# Repository Memory

## Stable Context
- **資料來源原則**  
  - 只以 GitHub Issue 與 Comment 為原始事實來源，任何長期記憶皆須以這些結構化資訊為根基。  
  - `shared/manual.md` 為人類手動維護的長期記憶檔，僅存放 **穩定規則、長期決策、常見限制與 repo 習慣**，不會被自動流程覆寫。  

- **repo 習慣**  
  - 所有新功能、缺陷、改進皆以 Issue 形式提出，並由多個 *issue agents* 於每日快照中彙整。  
  - 每日快照只在有可用 Issue 時產生主題、決策與開放迴路；若無則保留既有記憶。  
  - `compact‑memory` 工作流會讀取 `shared/manual.md`，但不會直接寫入或覆寫它。  

- **限制**  
  - **禁止** 直接複製 Issue 原文或長篇日誌於長期記憶檔。  
  - 必須將重複出現的資訊**蒸餾**為可重用的規則或上下文，而非逐段搬錄。  
  - 若資訊不足或相互矛盾，必須在本檔中標註「不確定」或「需進一步驗證」。
