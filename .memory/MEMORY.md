# Repository Memory

## Stable Context
- **記憶維護原則**  
  - 只保留 **穩定規則、長期決策、常見限制** 與 **repo 習慣**，不直接複製 Issue 原文。  
  - 所有資訊皆以 **GitHub Issue / Comment** 為唯一原始來源，手動筆記僅作為彙整與提醒。  
  - `compact‑memory` 工作流程會讀取本檔案，但 **不會覆寫**，因此本檔案必須保持 **只讀**、可追溯的狀態。  

- **目前可確認的長期事實**  
  - 近期 30 天內 **無可用 Issue** 被偵測到，代表專案目前處於靜止或缺乏待處理工作。  
  - 沒有跨 Issue 的共通主題、決策或標籤可供抽象化。  

> **不確定性**：因缺乏 Issue 資料，我們無法推斷主人在工作、生活或專案上的具體規律與偏好。若未來出現新 Issue，請重新評估並更新此段落。

## Recent Themes
- **無明顯重複主題**：過去一週（2026‑09‑22 至 2026‑09‑29）的每日快照皆顯示「本次整理視窗沒有可用 issue」，因此沒有可蒸餾的近期主題。  

> 若未來出現持續出現的關鍵字或標籤，請將其歸類於此節，並說明其頻率與可能的意圖。

## Constraints
1. **資料來源限制**  
   - 只能引用 **GitHub Issue / Comment**，不允許直接貼上原始 Issue 文字。  
2. **手動筆記規範**  
   - `shared/manual.md` 為唯一的手動維護入口，僅容納 **穩定規則、長期決策、常見限制、repo 習慣**。  
3. **更新頻率**  
   - 本檔案僅在 **有新穩定資訊** 時更新；每日快照若無新 Issue，則不改動本檔。  
4. **可讀性**  
   - 必須保持 **Markdown 結構清晰**，方便龍蝦（agents）與人類快速檢索。
