# Repository Memory

## Stable Context
- **資料來源**：本倉庫的長期記憶主要來自 **GitHub Issue / Comment**，而非每日快照的直接內容。  
- **手動筆記**：`shared/manual.md` 用於保存 **穩定規則、長期決策、常見限制** 以及 **repo 習慣**，此檔案不會被自動流程覆寫。  
- **工作流程**：  
  1. 每日快照會從過去 30 天內的活躍 Issue 中抽取資訊。  
  2. 若當日無可用 Issue，快照只會保留既有記憶，並在 **Open Loops** 中標示等待更新。  
- **限制**：  
  - 不得直接複製 Issue 原文於手動筆記或長期記憶檔案。  
  - 只能以 **精煉、抽象** 的方式呈現重複出現的概念或規則。  

> **不確定性**：目前在 2026‑08‑17 至 2026‑08‑23 的每日快照中，皆未偵測到任何可用 Issue，故無法從實務層面萃取新的穩定規則或決策。

## Recent Themes
- **無可辨識跨 Issue 主題**：連續七天的快照皆顯示「目前沒有可辨識的跨 issue 主題」。
- **持續無 Issue**：每日皆報告「本次整理視窗沒有可用 issue」，顯示近期工作項目可能已全部關閉或尚未建立。

## Constraints
1. **來源限制**  
   - 只能以 Issue / Comment 為原始資料來源，其他文件（如 README、Wiki）不列入自動記憶抽取。  
2. **內容精簡**  
   - 手動筆記必須保持 **compact**，避免冗長的原文複製。  
3. **更新頻率**  
   - 每日快照只檢視最近 30 天內的 Issue，若超過此範圍則不會被自動納入。  
4. **同步機制**  
   - `shared/manual.md` 由人類手動維護，系統僅在讀取時參考，絕不寫入或覆寫。
