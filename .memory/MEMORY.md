# Repository Memory

- **記憶手冊原則**  
  - 本檔案僅保存 **長期穩定規則、決策、常見限制與 repo 習慣**，不會直接複製 Issue 原文。  
  - 所有原始資訊仍保留於 GitHub Issue / Comment 中，供 agents 參考。  
  - `compact‑memory` 工作流程會讀取此手冊，但不會覆寫它。  

- **目前缺乏可辨識的長期事實**  
  - 從最近 30 天的 daily snapshots（2026‑11‑07 ~ 2026‑11‑14）中，未偵測到任何可重用的規則、決策或持續性主題。  
  - 因此 **沒有可歸類為「穩定」的生活或工作脈絡**，只能保留上述手冊原則作為基礎。

## Recent Themes

- **無新決策**  
  - 所有快照皆顯示「目前沒有新的跨 issue 決策」。

## Constraints
1. **資料來源限制**  
   - 只能從 GitHub Issue / Comment 取得原始資訊，手動筆記僅作為摘要與指引。  
2. **內容重複與版權**  
   - 不得完整複製 Issue 內容於本檔，必須以精煉、抽象的方式呈現。  
3. **更新頻率**  
   - 只有在有新 Issue 產生或現有 Issue 更新時，才會觸發 daily snapshot 的實質內容。  
4. **語氣與角色**  
   - 以「龍蝦」的視角記錄，保持友善且具工程可讀性的語調。
