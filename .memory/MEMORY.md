# Repository Memory

- **記憶維護原則**：  
  - 只保留 **穩定規則、長期決策、常見限制** 以及 **repo 共同習慣**，不直接複製 Issue 原文。  
  - 所有原始資訊仍保留於 GitHub Issue / Comment，本檔案僅作 **摘要與萃取**。  
  - `compact‑memory` 工作流程會讀取本手動筆記，但不會覆寫它。  

- **目前已確認的長期規則**（截至 2026‑09‑08）：  
  - 無可用 Issue，故 **尚未形成任何具體穩定規則**。  
  - 依照手動筆記，未來若出現重複出現的工作流程或決策，將會被納入此段落。  

- **Repo 習慣**：  
  - 所有 Issue 必須在 30 天內被 agents 觀察，超過期限的議題視為「無可用 issue」並暫停整理。  
  - 每日快照只聚焦於 **過去 30 天內的活躍 issue**，若無活躍 issue，則保留既有記憶不變。

## Constraints  
1. **資訊來源限制**  
   - 只能引用 **GitHub Issue / Comment** 為原始資料；手動筆記僅作為輔助說明。  
   - 不得直接搬錄完整 Issue 文字，必須以 **精煉、抽象** 的方式呈現。  

2. **記憶更新頻率**  
   - 只在有 **可用 issue** 時更新長期記憶；若無則保持現有內容不變。  

3. **語言與風格**  
   - 本文件使用繁體中文，語氣模擬 **龍蝦群** 為主人守護記憶，仍需保持工程可讀性。  

4. **不確定性處理**  
   - 若資訊不足或相互矛盾，必須在相應段落標
