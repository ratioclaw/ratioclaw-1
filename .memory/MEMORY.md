# Repository Memory

## Stable Context
- 目前的資料顯示在過去兩週內 **沒有可用的 Issue** 被產生或更新，故尚未形成可辨識的長期規則或決策。  
- 依照 **Shared Memory Manual Notes**，以下原則被視為穩定且全域適用的 repo 習慣：  
  1. **GitHub Issue / Comment 為唯一原始資料來源**，所有記憶的抽取與整理必須以此為根基。  
  2. **shared/manual.md** 只用來手動保存長期規則、決策與限制，**不會被自動覆寫**，亦不應直接複製完整的 Issue 內容。  
  3. **compact‑memory workflow** 會讀取此手動筆記以提供上下文，但不會改寫它。  

> **不確定性**：因缺乏實際 Issue 討論，我們無法確認任何業務流程、技術選型或團隊慣例是否已固定。若未來出現持續出現的主題，請將其搬移至此節。

## Recent Themes
- 最近 30 天的每日快照皆顯示 **「本次整理視窗沒有可用 issue」**，因此沒有可辨識的跨 Issue 主題或重複出現的討論焦點。  
- 若未來出現新 Issue，請留意是否有以下類型的重複出現：  
  - 功能需求（Feature Requests）  
  - Bug 報告（Bug Reports）  
  - 內部流程改進（Process Improvements）  

## Constraints
- **資料來源限制**：只能從 GitHub Issue 與其評論中抽取資訊，其他渠道（如 Slack、電子郵件）不列入本記憶庫。  
- **內容授權**：shared/manual.md 內的手動筆記必須保持 **摘要式**，避免直接貼上 Issue 原文，以免侵犯原始作者的版權或造成資訊冗餘。
