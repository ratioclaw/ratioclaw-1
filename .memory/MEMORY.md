# Repository Memory

## Stable Context
- 目前的日誌與快照皆顯示 **沒有可用的 Issue**，因此尚未形成可供長期參考的規則或決策。  
- 依照 **Shared Memory Manual Notes** 的指示，以下原則被視為穩定且永續適用於本倉庫：  
  1. **資料來源**：所有可追溯的事實必須來自 GitHub Issue 或 Comment，手動筆記僅作為輔助摘要。  
  2. **手動筆記的角色**：`shared/manual.md` 只供人類編輯與維護，不會被自動流程覆寫，也不應直接複製完整 Issue 內容。  
  3. **compact‑memory 工作流程**：會讀取 `shared/manual.md` 作為長期記憶的基礎，但不會改寫其中的內容。  
- 以上三點構成目前唯一可確認的 **長期穩定上下文**。

## Constraints
| 限制項目 | 說明 |
|----------|------|
| Issue 為唯一事實來源 | 任何記憶、決策或規則必須以 Issue / Comment 為根據，避免依賴非結構化或臨時筆記。 |
| 手動筆記不可被自動覆寫 | `shared/manual.md` 只供人類手動更新，系統不會自動修改或刪除其中內容。 |
| 不複製完整 Issue 文字 | 為保持精簡與可讀性，摘要應抽象化為規則或決策，而非逐段搬錄原文。 |
| 需要 Issue 才能產生 Open Loop | 若無 Issue，系統無法辨識待處理的未完成事項，故「Open Loops」將保持空白。 |
