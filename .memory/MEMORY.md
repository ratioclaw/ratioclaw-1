# Repository Memory

## Stable Context
- **記憶手冊規範**  
  - 只保留 **穩定規則、長期決策、常見限制、repo 習慣**，不直接複製 Issue 原文。  
  - 原始資料來源必須是 **GitHub Issue / Comment**，手動筆記僅作為彙整參考。  
  - `compact‑memory` 工作流程會讀取此手動筆記，但不會覆寫它。  

- **目前觀測**  
  - 在過去 30 天的每日快照中，**未偵測到任何可用 Issue**，因此無法抽取新的穩定事實或規則。  
  - 代理人未報告跨 Issue 主題或決策，表示目前的工作項目處於靜止或已全部完成。

> **不確定性**：因缺乏活躍 Issue，無法確認主人在此期間是否有隱藏的長期目標或慣例。若未來出現新 Issue，請重新評估並更新此節。

## Recent Themes
- **無明顯主題**：最近一週（2026‑11‑21 至 2026‑11‑28）的所有快照皆顯示「沒有可用 Issue」且「沒有跨 Issue 主題」。  
- **待觀察**：若未來出現持續出現的標籤、關鍵字或任務類型，將在此節匯總為近期主題。

## Constraints
1. **資料來源限制**  
   - 只能從 GitHub Issue / Comment 抽取資訊，手動筆記僅作為輔助。  
2. **內容編寫原則**  
   - 不直接複製原始 Issue 文字；必須以 **精煉、可重用** 的方式呈現。  
   - 只保留 **長期有效** 的規則或決策，短暫或一次性的資訊應歸入「Open Loops」或「Recent Themes」。  
3. **更新頻率**  
   - 每日快照若無新 Issue，則保留既有記憶，不產生變更。  
4. **語氣與風格**  
   - 以 **龍蝦群** 的口吻記錄，保持工程可讀性與友善語調。

## Open Loops
- **等待 Issue 更新**：目前所有快照皆顯示「等待下一輪 Issue 更新後再整理」。此為唯一未解決的循環任務
