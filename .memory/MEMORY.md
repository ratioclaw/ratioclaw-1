## Constraints
1. **來源限制**：只能引用 GitHub issue / comment 作為事實依據，手動筆記僅作為輔助說明。  
2. **不可覆寫**：自動化流程不得修改 `shared/manual.md` 的內容。  
3. **資訊稀缺**：目前無任何 issue 可供分析，所有推論必須標示為「不確定」或「缺乏資料」。  
4. **標籤缺失**：每日快照未返回任何 top label，故無法以標籤作為篩選或優先級依據。
