- **手動筆記原則**：  
  1. 只保留 **穩定規則、長期決策、常見限制、repo 習慣**，不直接複製 issue 原文。  
  2. 任何自動化流程（如 compact‑memory workflow）會讀取此手動筆記，但不會覆寫它。  
- **資料來源限制**：  
  - 真正的原始資訊必須來自 GitHub issue / comment；若缺少此類資料，則無法生成具體記憶條目。  
- **資訊完整性**：  
  - 若資訊不足或相互矛盾，必須在此文件中明確標示為「不確定」或「待確認」。
