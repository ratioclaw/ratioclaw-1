# Repository Memory

## Stable Context
- **資料來源原則**：所有可追溯的事實與決策必須以 GitHub Issue 或 Comment 為唯一原始來源。  
- **手動筆記角色**：`shared/manual.md` 只保留 **長期穩定規則、決策、限制與 repo 習慣**，不會被自動流程覆寫，也不應直接複製 Issue 內容。  
- **Compact‑Memory 工作流**：此工作流會在每次執行時讀取 `shared/manual.md`，但不會寫入或改寫它；因此手動筆記是 **只讀的長期記憶基礎**。  
- **目前缺乏可用 Issue**：過去 30 天的 daily snapshots 均顯示「本次整理視窗沒有可用 issue」，因此尚未累積任何可供蒸餾的穩定規則或決策。  

> **不確定性**：因為缺少 Issue 資料，無法確認是否已有隱含的長期規則尚未被捕捉。若日後出現新 Issue，需重新評估並補充此段落。

## Recent Themes
- **無跨 Issue 主題**：在 2026‑10‑04 至 2026‑10‑13 的所有快照中，系統未偵測到任何重複或跨 Issue 的主題。  
- **暫無新決策**：同樣沒有新產生的跨 Issue 決策可記錄。  

> **觀察**：目前的「近期」狀態即是「無資訊」。若未來出現持續出現的議題，請將其歸類於此節。

## Constraints
1. **不複製原始 Issue 文字**：手動筆記與 MEMORY.md 必須以摘要或規則形式呈現，避免直接搬錄 Issue 內容。  
2. **依賴 Issue 為唯一事實來源**：任何新增的長期記憶必須先在 Issue 中得到驗證或討論
