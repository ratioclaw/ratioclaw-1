## Constraints
1. **Issue 為唯一原始資料來源**：所有記憶的抽取、更新與跨議題分析皆必須基於 GitHub issue / comment。  
2. **每日快照限制**：  
   - 只檢視最近 30 天內、最多 100 個 issue。  
   - 若無符合條件的 issue，快照將不產生任何內容（如目前所見）。  
3. **手動筆記不可被覆寫**：`shared/manual.md` 只作為長期記憶的補充說明，系統不會自動寫入或修改其中的內容。  
4. **缺乏資訊即視為不確定**：若無法從 issue 中確認的事實，必須標示為「資訊不足」或「不確定」。

## Open Loops
