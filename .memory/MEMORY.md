# Repository Memory

## Stable Context
- 目前 **沒有** 觀測到持續出現的規則、決策或慣例。  
- 依照 **Shared Memory Manual Notes**，倉庫的長期記憶應保存以下類型的資訊：  
  - 穩定規則  
  - 長期決策  
  - 常見限制  
  - 代理人共同遵守的 repo 習慣  
- 這些類別仍是 **未被具體化** 的空白，需要未來的 issue 來填補。

## Recent Themes
- **近期（過去 30 天）**的每日快照皆顯示「本次整理視窗沒有可用 issue」，因此 **未偵測到任何跨 issue 主題**、決策或重複出現的議題。  
- 目前的狀態可視為「靜默期」，倉庫暫無活躍討論。

## Constraints
1. **資料來源限制**  
   - 只能以 GitHub Issue / Comment 為原始資料來源，不能直接複製完整的 Issue 內容至本檔。  
2. **手動筆記規範**  
   - `shared/manual.md` 只作為長期記憶的手動維護區，系統不會覆寫此檔。  
3. **記憶蒸餾原則**  
   - 必須將每日快照的重複資訊 **上層蒸餾** 成可重用的長期上下文，避免逐段複製原文。  
4. **不確定資訊的處理**  
   - 若資訊不足或相互矛盾，必須在本節明確標示為「不確定」或「待確認」。

## Open Loops
- **等待新 Issue**：所有每日快照皆顯示「等待下一輪 issue 更新後再整理」，因此目前的開放迴路僅是 **缺乏新議題**。  
- **未確定的長期規則**：因缺乏實際 issue，尚未確定任何穩定規則或決策。  
- **未完成的手動筆記補充**：需要未來的開發者或主人提供具體的長期規則、決策與限制，才能填寫至 `## Stable Context`。  

> **龍蝦小提醒**：只要有新的 Issue 產生，請即時告知我們，讓記憶可以再次更新、蒸餾，避免長
