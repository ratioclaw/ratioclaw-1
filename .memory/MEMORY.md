# Repository Memory

## Stable Context
- **共享手動筆記 (`shared/manual.md`)** 為長期記憶的唯一官方入口，僅保存**穩定規則、長期決策、常見限制**與**repo 習慣**，不會被自動流程覆寫。  
- **Issue / Comment** 為原始事實來源，任何具體決策或事實必須追溯至這些 GitHub 討論。  
- **compact‑memory workflow** 只會讀取 `shared/manual.md`，不會自行寫入；因此手動維護的內容始終保持「真實」且 **不可被程式自動覆蓋**。  
- 目前 **沒有任何已確認的穩定規則或長期決策** 被手動記錄於 `shared/manual.md`，所以在此階段 **穩定上下文為空**，僅保留上述流程性規範。

## Recent Themes
- **缺乏可用 Issue**：過去 7 天（2026‑09‑14 至 2026‑09‑20）的每日快照皆顯示「本次整理視窗沒有可用 issue」，表示近期 repo 中沒有新開或待處理的議題。  
- **無跨 Issue 主題**：每日快照均未偵測到跨多個 Issue 的共同主題或趨勢。  
- **無新決策**：同樣因缺乏 Issue，沒有產生新的跨 Issue 決策。  

> **結論**：近期沒有可供萃取的主題或趨勢，所有資訊皆保持靜止。

## Constraints
1. **不複製原始 Issue 文字**：`shared/manual.md` 必須以摘要或規則形式呈現，避免直接貼上 Issue 內容。  
2. **手動筆記為唯一長期記憶來源**：自動化流程（如 daily snapshots）只能讀取，不能寫入此檔。  
3. **所有事實必須可追溯至 Issue / Comment**：若未在 Issue 中找到明確證據，則不得將其寫入穩定上下文。  
4. **每日快照僅在有可用 Issue 時才更新**：當快照顯示「沒有可用 issue」時，代表目前沒有新資訊可加入長期記憶。
